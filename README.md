# Al Saeed Quran Institute

Online Quran learning platform built with Vue 3, Vite and Tailwind CSS.

## Features

- Online Quran Classes
- Tajweed Course
- Hifz Program
- WhatsApp Integration
- Responsive Design
- SEO Friendly

## Tech Stack

- Vue 3
- Vite
- Tailwind CSS
- Vue Router

## Deployment

Hosted on Vercel.
